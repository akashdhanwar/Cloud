WHAT IS IAM

Provide/Defines Granular Permission
Permissions are defined by IAM Policies
We can apply policies to IAM Users/ User Group/IAM Role. These are called identity based policies. Providing to Group is a good idea.
IAM Role can be assumed by any resource on AWS and can grant access to other resources. It can also be programmatically assumed by an application
IAM Role access keys automatically rotate by design
By default, IAM user has no access to AWS account
After getting permission to service or resource, IAM user can access it by Console/CLI
Using CLI, IAM user will connect by using access keys. Using Console, they use Username and Password
Long time access keys are a security risk. Schedule automatic rotation of IAM access keys

Additional IAM Tools 
IAM Access Analyzer - Identify resources with external access and can alert us, validate IAM Policies and generate IAM Policies based on usage 
IAM Policy Simulator - Test new IAM policies before granting them to users, user groups and roles

LEVERAGING EXISTING IDENTITY PROVIDERS

Federated Identities - 
Sometimes organization already have there own identity management system like Microsoft Authenticated Directory(AD). 
To provide access We can leverage these existing identity providers in a process called Federated Identity
The service that uses to do this is IAM Identity Center and it is a more secure way to give access to AWS resources than creating IAM user
You are using IAM Role, when the user sign in using single sign on they are temporarily assumed this role and use that role to access AWS resources

IAM Identity Center allows AWS users to leverage Single Sign-On to temporarily assume a role each time they login 

We can also use IAM Identity Centre as a directory

Web Federated Identities -
Suppose we have application and we want users to use the application. AWS provides Web Federated Identities for authentication. We will be checking with some other identity provider, it will return token to AWS
Amazon Cognito is the service for Web Federated Identities
Creates user pools and grant temporary keys to customers to give access to your application
Leveraging social or enterprise identity providers for authentication.

AWS Directory service -
It is used to connect IAM Identity Center to Microsoft AD.
Connect your AWS ecosystem with an existing Microsoft Authenticated Directory
Host managed Microsoft AD on AWS

AWS Security Token Service -
If we want to give temporary read only permission like to auditor
We can create IAM 
But with STS, we provide temporary access which will allow them to use temporary IAM role

IAM Identity Center can be used in conjuction with AWS Directory Service to achieve federated authentication for your AWS users
Amazon Cognito allows you to securely authenticate application users, leveraging web identity federation

KEEPING SECRETS SAFE

Secrets means sensitive data like customer data 
Encryption At Rest means protecting data in place 
Encryption In Transit means protecting data while it is on the move

Encryption At Rest - S3 -
S3 is encrypted by default using serverside SSE-S3 Manged keys. All S3 buckets are server side encrypted by default upon creation
Amazon Macie used ML to search your S3 buckets for PII(personally identifiable information)

Encryption At Rest - Elastic Block Store -
We use key from Key Management Service(KMS)

Encrption At Rest - RDS
We can use KMS but if RDS not encrpted then create a copy of RDS and encypt by KMS
To encrypt an RDS instance, you must create a copy and encrypt the copy. Original cannot be encrypted

Encryption In Transit -
Traffic within Amazon VPC is encrypted by default
For public, use HTTPS protocol. It encrypts data in transit with the Transport Layer Security(TLS) protocol
Check if HTTPS enabled using Certification Manager which allows to provision, deploy and automatically renew public or private SSL/TLS certificate

Systems Manager Parameters Store -
For usernames and passwords
Keeps these access and provides programmatic access on AWS
It can securely store passwords, database strings and other values for reference

Secrets Manager -
It adde another layer of security by enabling automatic rotation of your secrets

EXPLORING NETWORK SECURITY SERVICES

Network access control lists(NACLs)
Provide stateless access control in your VPCs and subnets
Using it we limit resources that can use your VPC resources

Security Groups 
Similarly security groups provide stateful access control for prticular resources

Together, security groups and network access control lists can help you define granular access control for resources in your Amazon VPCs
But sometimes you need more to keep bad guys out 

AWS Network Firewall
Network firewall not only filters based on origin but can also define complex rules to inspect traffic within your VPCs

Not everything is on VPC. You may have api gateway endpoint 

AWS WAF
AWS Web Application Firewall
AWS WAF protects your web applications from common exploits like SQL injection or Cross site scripting

AWS Shield
To prevent DDoS attack
Shield Standard is protects your AWS resources from DDoS at no extra cost
Shield Advanced provides expanded protection and access to a 24/7 DDoS response team

AWS Firewall Manager 
Manages Network Firewall, AWS WAF, AWS Shield
Helps you administer your network security from a single service

WHAT IS SECURITY HUB

Supports a bunch of security and configuration services 
Firewall Manager - Sends findings on unprotected resources and suspected DDoS attack is under way
Guard Duty - Tracks activity logs across your AWS account, sends findings in response to malicious behaviour
Inspector - Inspects your workloads for vulnerabilities and network access, sends its findings to Security Hub
Macie - Searches S3 buckets for sensitive information including PII and sends its findings to Security Hu 
Systems Manager - Patch Manager detects noncompliant resources and sends findings to Security Hub
Config - Uses detective guardrails to find noncompliant resources and sends findings to Security Hub
IAM Access Analyser - Detects externally accessible resources or unused access and reports findings to Security Hub
AWS Health - Reports service outages relevant to your AWS resources and sends findings to Security Hub


Aggregates findings across AWS ecosystem. Prioritize security events and determine the best way to take action
