- Metrics, Logs and Configurations
Collecting and monitoring these is critical to the health of your AWS ecosystem
Metrics - Numerical representations of things like capacity and demand, tracked over time 
Logs - A record of what has happened, to make sense of errors or security events
Configurations - Settings and guidelines across all of your cloud resources

- Collecting Metrics
AWS services can publish metrics 
Metrics help monitor workload health
Metrics inform design decisions
Common examples - Lambda invocations or errors, EC2 CPU utilization, RDS read latency, Custom application metrics

We can create charts or alerts on scenarios, Trigger automated events

- Log Producers
Merrics are derived from logs 
Logs track actions on your infrastructure
Common Examples - VPC flow logs, EC2 Instance logs, Account Activity logs, Application logs

- Configuration Management
Configurations are resource settings or standards
Types and properties of resources can be standardized across your AWS environment
Seek guidance and enforce best practices with AWS services

Configurations require monitoring - Standardized configurations require both prevention and detection
Automate Configurations at Scale - We will be leveraging AWS services to automate enforcement and auditing of configurations

EXPLORING AMAZON CLOUDWATCH AND AWS CLOUDTRAIL DIFFERENCES

Cloudwatch 
Gives visibility to cloud resources and applications
Tracks metrics in dashboards
Stores logs from many sources 
Trigger events with CloudWatch Alarms
Cloudwatch lets you watch your cloud resources as your aws ecosystem evolves

Cloudtrail
Provides accountability for actions taken in your account 
Centralizes activity logs across regions in an S3 bucket
Tracks only API activity in your AWS account
CloudTrail creates a trail of breadcrumbs for any action in your account

CloudWatch
For EC2 application and some instance metrics cant be collected unless you install the CloudWatch agent on the instance 
Metrics requiring CloudWatch Agent - Free Memory, Percentage of Disc space used, Custom application metrics and many more

CloudTrail always leaves a trail
