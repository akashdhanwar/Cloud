AWS GLOBAL ACCELERATOR

It is a Networking Service that sends your user traffic through AWS Global Network Infrastructure 
It is a express lane in CDN that bypass the regular traffic and gets important pizzas delivered quicker
Uses Caching to find optimal path to nearest regional endpoint

- Benefits
Improved Performance                -   Increases throughput up to 60%
Simplified Traffic Management       -   User can access your application endpoints through static IP addresses
Security and Reliability            -   DDoS Resiliency, Automatic Reroute
Consistent Global User Experience   -   Intelligent routing sends user traffic to the endpoint that provides the best performance

- Use Case
Global User Base, High Traffic Events, Multi-Region applications, Latency-Sensitive Applications

NETWORKING: THE BIGGER PICTURE 

Amazon VPC 
Secure Isolated section of a cloud kitchen
We have full control over virtual networking environment including arrangements of workstations/subnets, access rules/security groups and connections to outside worlds like internet gateways

Inside AWS Cloud, we have Amazon VPC
VPC further have subnets which further segments our VPC allowing us to organizing our resources and add layers of security
We have AZ in VPC which have subnets. We have a public subnet and a private subnet
We have route tables and Network access control list for both subnets
Internet gateway acts as a bridge between VPC and Internet 
Inside each subnet, we have security group that manages inbound and outbound traffic

Public subnets - Resources here can be accessed from the internet
Private subnets - Not directly accessible from the outside world

Internet gateway - Main door to the outside world. When we attach Internet Gateway with VPC, it is responsible for routing outing requests and incomming traffic

Route Tables - Instructions for staff from where to take ingredients. They have entries(routes) that determine where network traffic from your subnets should go
Each subnet in VPC must be associated with a route table

Security in VPC
Security Groups - act as guidelines what is allowed in and out of each area of your kitchen
Guarding at home in society
Operate at instance level 
Allow you specify allowable protocols, ports and source/destination IP ranges
Security groups are stateful - if out traffic is allowed for some, then in is automatically allowed

Network Access control list - Provides extra layer of security providing set of rules that control traffic in and out of the subnets
Guards at gate of society
Operate at subnet level
They are stateless
They can allow or deny traffic based on protocol, port, and source/destination IP address

LAUNCH AN EC2 INSTANCE IN A VPC

VPC > Create > VPC only > Add 10.0.0.0/16 in ipv4 > Create
Create subnet > Left sidebar Subnets > Create > Add VPC id > ipv4 same as above > Create
Make subnet public > Select subnet > Actions > Modify auto assign ip settings > Enable > Save > Left Internet Gateway > Create > Actions > Attach to VPC > Attach
Configure routing for public > Left Route Tables > Create > Edit routes > Add > Dest as 0.0.0.0/0 > Target will be internet gateway > Save 
Associate route table to public subnet > Subnet Associations > Edit > Select > Save 
EC2 > Launch instance > Create key pair > Launch > View all
Select instance > Connect > EC2 instance connect > Connect
