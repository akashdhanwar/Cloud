WHAT IS AMAZON ATHENA 

Athena enables us to run standard SQL queries on data stored in S3 

An interactive query service 
Serverless, nothing to provision, pay per TB scanned 
No need for complex Extract/Transform/Load(ETL) processes 
Works directly with data stored on S3

Use Case 
Query log files stored in S3 
Analyse AWS Cost and Usage reports
Generate business reports on data stored in S3 
Run queries on click stream data 

Interactive Query       -   Athena is a interactive querty service for data in S3 
Standard SQL            -   Allows you to query data stored in S3 using standard SQL 
Serverless              -   You dont need to configure any infrastructure to use Athena 
Use Case                -   Querying log files or generating reports from S3 data

DEMO: USING ATHENA TO QUERY DATA 

Scenario    -   You would like to use standard SQL to query a log file that is located in S3 using Athena 

1   -   Configure Cloudtrail create some log data   -   Cloudtrail > Create trail > default > create trail 
2   -   Create S3 bucket for Athena results         -   S3 > Create bucket > default
3   -   Query the data using Athena                 -   Athena > Query editor from left menu > Setup query result loc > Settings > Manage > Browse S3 > Save > Editor > CREATE DATABASE athenadb > Run Query 

Populate data in database - https://github.com/pluralsight-cloud/AWS-Certified-Cloud-Practitioner-CCP-CLF-C02 > AthenaDemo > Athena_Query > Replace location of S3

EXPLORING MANAGED STREAMING FOR APACHE KAFKA(Amazon MSK)

Fully managed Apache Kafka that process streams of events from hundreds of event sources
Used to build real time streaming Applications

Apache Kafka    -   Widely used open-source technology used to build real-time data streaming pipelines 
                    Process stream of events from hundreds of event sources
                    Data consumers read the data and process it in the order it was produced
Apache Kafka Clusters can be difficult and time consuming to setup. So with MSK, AWS does heavy lifting for us including provisioning the cluster, configuring Apache Kafka, and managing upgrades 
Monitoring, replacing unhealthy nodes, and scaling up when needed
Its like Kinesis.

Use Case        -   Stock market data analysis in real time
