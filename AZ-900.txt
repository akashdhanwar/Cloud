What is Cloud Computing -
The cloud is just someone else's computer
What makes it special - The ability to rent computing resources - on demand
1000+ services

Web App - run code in the cloud without managing a VM
Function App - run small code in the cloud without a server
Logic App - A workflow, perform a series of steps
AI, Blockchain, Marketplace, etc..

Shared Responsibility Model -
Users and Customer have divided responsibility
On-Premises - We are responsible for all like Building security, Physical network, Physical computer, OS patches, Network and Firewall, Application settings, Auth platform, User accounts, Devices, Data 
Cloud Virtual Machine(IaaS) - First 3 by Azure. Others by Client
Cloud App Service(PaaS) - First 4 by azure. .Next 3 combined. Others by Client
Cloud SaaS - First 6 by azure. Next one combined. Others by Azure

Public, Private and Hybrid Cloud -
Public - Computing service offered by third party providers over the public internet, making them available to anyone who wants to use or purchase them. Azure owns the hardware, on their network and infrastructure.
Private - Computing services offered either over the internet or a private internal network and only to selected users instead of the general public. Looks and acts like a cloud, except customer owns or leases or has exclusive access to the hardware.
Hybrid - Computing environment that combines private with public cloud. 

Cloud Pricing -
Cloud pricing can be complicated
Downsides - Difficult to predict your monthly bill
 Difficult to understand in advance what a service will really cost
 Possibility of big savings but you loose predictability
Factors affecting VM pricing -
Geographical region, OS, Instance Size, Disk size or type, Bandwidth, Backup storage, Reservation/Savings Plan, Support Agreement, API Choice, Region/Regions, Standard/Serverless Model, Number of operations per second, Consumed Storage, Optical Dedicated Gateway, Backup storage
There are many Free Services as well
Pay for time - Sime services charge by time used
 Stop using the service to stop the charges. i.e. Virtual Machine Instances
Pay for GB - Usually you pay for any data storage used
 Fairly cheap - $0.02 per GB per month
 Also pay for network traffic to/from other regions, or to the internet
Pay for Operations - Can also be charged per operation
 Operations are read, write, list, delete
 Pay per message, pay per query to a database, etx
 Usually very cheap operation
